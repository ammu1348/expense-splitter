# Expense Splitter 💰

A simple, responsive, and user-friendly Expense Splitter web application that helps groups manage shared expenses, split bills, and calculate balances automatically.

## 🚀 Live Demo

**[Visit Expense Splitter](https://expense-splitter-beta-green.vercel.app/)**

## 📌 About The Project

Expense Splitter makes it easy to track group expenses and manage shared payments. Users can add group members, record expenses, select who paid, choose participants for splitting, and automatically calculate individual balances.

## ✨ Features

- Add and remove group members
- Record shared expenses
- Select who paid for an expense
- Split expenses among selected members
- Automatically calculate individual balances
- Delete recorded expenses
- Save data using LocalStorage
- Clear all data with confirmation
- Responsive design for desktop and mobile

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- LocalStorage
- IBM Plex Fonts

## ⚙️ Getting Started

### Clone Repository

```bash
git clone https://github.com/ammu1348/expense-splitter.git
```

### Navigate to Project

```bash
cd expense-splitter
```

### Run Project

Open `index.html` in your browser or use the VS Code Live Server extension.

## 💾 Data Storage

This application uses browser LocalStorage to save group members and expense records. Data remains available in the same browser unless cleared.
